# Banco de Dados

Materiais das aulas de Banco de Dados (MySQL).

## Detran

Banco de exemplo com veículos, proprietários, endereços, contatos, roubos/furtos e benefícios. Os dados são fictícios e usam cidades do Maranhão.

| Pasta | Arquivo | Para que serve |
|---|---|---|
| `detran/1-estrutura` | `detran.sql` | Cria o banco `Detran` e as 6 tabelas |
| `detran/2-dados` | `detran_inserts.sql` | Insere os dados de exemplo |
| `detran/3-exercicios` | `lista_exercicios_select.sql` | 45 questões de SELECT para resolver |

### Como usar

1. Rode `detran.sql` no MySQL (Workbench ou terminal).
2. Rode `detran_inserts.sql` com as tabelas ainda vazias.
3. Abra `lista_exercicios_select.sql` e escreva o seu SELECT abaixo de cada questão.

Para baixar tudo de uma vez: botão verde **Code** → **Download ZIP**.
